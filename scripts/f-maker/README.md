

# CVA6 File Tree Copier

This Python script (`f-maker.py`) is a utility designed to copy a specific subset of files from the CVA6 RISC-V core project. It uses a `.f` file list, typically generated by the `bender` tool for a Verilator simulation, to identify the necessary source files.

The main purpose of this script is to create a clean, portable directory that contains only the required files for a specific CVA6 configuration, while perfectly preserving the original directory structure. This is useful for creating a minimal project subset for version control, distribution, or further processing.

## How It Works

The script performs the following steps:

1.  **Reads the Input `.f` File**: It takes the path to a `.f` file as an argument. This file contains a list of all source files and compiler flags needed for the Verilator simulation.
2.  **Parses File Paths**: It iterates through each line of the `.f` file. It ignores empty lines and lines that are compiler directives (e.g., those starting with `+` or `-`).
3.  **Filters for CVA6 Scope**: It specifically looks for file paths that belong to the `cva6` project directory.
4.  **Recreates Directory Structure**: For each valid file, it determines its path relative to the `cva6` root directory. It then recreates this same directory hierarchy inside a new destination folder.
5.  **Copies Files**: It copies each source file from its original location to the corresponding path in the new destination folder.
6.  **Reports the Outcome**: Finally, it prints a summary of how many files were successfully copied and how many were skipped (e.g., because they were not found).

## Usage

Follow these steps to use the script:

**Step 1: Generate the `.f` File with Bender**

First, you need to generate the file list using the `bender` command. The target (`-t`) will depend on your desired CPU configuration.

```bash
bender script verilator -t <your_cpu_target> > my_verilator_files.f
```

**Example:**

```bash
bender script verilator -t cv32a6_imac_sv32 > cv32a6_imac_sv32_verilator.f
```

**Step 2: Run the Python Script**

Now, run the `f-maker.py` script, providing the path to the `.f` file you just created.

```bash
python3 f-maker.py <path_to_f_file> [optional_destination_dir_name]
```

**Examples:**

*   **Basic Usage (default destination `cva6_copied`):**

    ```bash
    python3 f-maker.py cv32a6_imac_sv32_verilator.f
    ```

*   **Specifying a Custom Destination Folder:**

    ```bash
    python3 f-maker.py cv32a6_imac_sv32_verilator.f my_cva6_subset
    ```

After running, a new folder (e.g., `cva6_copied` or `my_cva6_subset`) will be created in the same directory as the script. This folder will contain the clean, structured subset of your CVA6 project files.
