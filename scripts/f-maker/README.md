
# CVA6 File Tree Copier and .f File Updater

This Python script (`f-maker.py`) is a utility designed to copy a specific subset of files from the CVA6 RISC-V core project and generate a portable `.f` file list. It uses a `.f` file list, typically generated by the `bender` tool for a Verilator simulation, to identify the necessary source files.

The main purpose of this script is to create a clean, portable directory that contains only the required files for a specific CVA6 configuration, while perfectly preserving the original directory structure. Additionally, it generates a new `.f` file where absolute paths are replaced with the `${CVA6_ROOT}` environment variable, making your project completely independent of the original root path.

## How It Works

The script performs the following steps:

1.  **Reads the Input `.f` File**: It takes the path to a `.f` file as an argument. This file contains a list of all source files and compiler flags needed for the Verilator simulation.
2.  **Parses and Rewrites File Paths**: It iterates through each line of the `.f` file. If a line contains the `/cva6/` path, it extracts the relative path and replaces the absolute prefix with `${CVA6_ROOT}`.
3.  **Handles Compiler Flags**: It correctly identifies compiler directives (e.g., `+incdir+`, `-v`) and injects the `${CVA6_ROOT}` variable right after the flag, ensuring that include directories and other flagged paths are also made portable.
4.  **Generates a New `.f` File**: It creates a new file named `<original_name>_New.f` containing these updated, portable paths.
5.  **Recreates Directory Structure**: For each valid file path belonging to the `cva6` project, it determines its path relative to the `cva6` root directory and recreates this same directory hierarchy inside a new destination folder.
6.  **Copies Files**: It copies each source file from its original location to the corresponding path in the new destination folder.
7.  **Reports the Outcome**: Finally, it prints a summary of how many files were successfully copied, how many were skipped (e.g., because they were not found), and the exact location of the newly generated `.f` file.

## Usage

Follow these steps to use the script:

**Step 1: Generate the `.f` File with Bender**

First, you need to generate the file list using the `bender` command. The target (`-t`) will depend on your desired CPU configuration.

```bash
bender script verilator -t <your_cpu_target> > my_verilator_files.f
```
**Example:**

```bash
bender script verilator -t cv32a6_imac_sv32 > cv32a6_imac_sv32_verilator.f
```
**Step 2: Run the Python Script**

Now, run the `f-maker.py` script, providing the path to the `.f` file you just created.

```bash
python3 f-maker.py <path_to_f_file> [optional_destination_dir_name]
```
**Examples:**

*   **Basic Usage (default destination `cva6_copied`):**

    ```bash
    python3 f-maker.py cv32a6_imac_sv32_verilator.f
    ```
    *This will create a `cva6_copied` folder and a `cv32a6_imac_sv32_verilator_New.f` file.*

*   **Specifying a Custom Destination Folder:**

    ```bash
    python3 f-maker.py cv32a6_imac_sv32_verilator.f my_cva6_subset
    ```
    *This will create a `my_cva6_subset` folder and a `cv32a6_imac_sv32_verilator_New.f` file.*

After running, a new folder will be created containing the clean, structured subset of your CVA6 project files, along with the `_New.f` file that you can use with your `${CVA6_ROOT}` environment variable.
